# AI Fare

一个本地 macOS 悬浮计价器：读取 Codex 的本地 SQLite 状态和 session 日志，按套餐额度显示当前任务的人民币分摊费用。

## 运行

```sh
swift run
```

计价器会出现在主屏幕右上角，可直接拖动。它只读取 `~/.codex/state_5.sqlite`，不会上传本地对话、路径或用量数据。

下次从 Finder 打开 `桌面/计价器/AI Fare.app`。右上角 `×` 会完全退出；“查看明细”页面用“← 返回计价器”回到主计价器。

## 计价说明

Plus 用户不应以 API 标价估算“已花的钱”。MVP 读取 Codex 写入 session 日志的 5 小时与周额度使用比例，以 `¥144 × 本周已用比例` 算出套餐分摊，再按照当前任务 Token 占今天活跃任务 Token 的比例分配到本次任务。跳表每 5 秒用本地额度记录校准。

这不是实际逐 Token 账单，而是帮助理解套餐额度消耗的本地分摊指标。后续会把月费和套餐类型移入可编辑设置。
